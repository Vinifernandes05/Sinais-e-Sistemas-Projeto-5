# Projeto 5 — pacote final
- `projeto5_apresentacao_final.html`: apresentação (15 slides + 2 de apêndice). Setas/espaço/PageUp-Down, botões ◀ ▶, `F` ou ⛶ = tela cheia. Gerada por `python3 gerar_apresentacao.py` a partir de `projeto5_template.html`.
- `analise_sistemas.py`: núcleo (zeros, polos, ROC causal, estabilidade). `app_streamlit.py`: interface (`pip install -r requirements.txt`; `streamlit run app_streamlit.py`).
- `analise_polos_zeros.py`: gera os resultados dos Modelos A/B. `test_analise.py`: testes (`python3 test_analise.py`).
- Slide 14: analisador em JavaScript (porte do Python, sem dependências externas); o Streamlit é a versão Python completa.
